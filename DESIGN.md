# Native design contract

Digital Audio Manager shares Tubify's native Python/PySide6 and QML foundation. The reference is [Tubify's native specification](https://linear.app/nouvelle-lune-atelier/issue/LUNE-367/publish-native-qol-roadmap-and-revised-player-specification); the app-specific migration is [LUNE-625](https://linear.app/nouvelle-lune-atelier/issue/LUNE-625/replace-the-web-wrapper-with-a-tubify-style-native-desktop-app).

Use Classic by default and offer Tubify's theme presets, including Midnight Violet. All controls use semantic colors from `theme.py`, Roboto typography and `qml/Theme.js` spacing and corner radii. Navigation and collection shortcuts sit on the left, search and account actions at the top, and a floating 92 px player with 12 px outer margins at the bottom. A queue dock appears when there is enough room; smaller windows retain a full Queue page. Lists are virtualized, artwork loads asynchronously, and controls expose keyboard focus and readable labels.

The app manages files and device exports and plays local audio through Qt Multimedia. The floating player uses Tubify’s controls, artwork, seek and volume layout. The top search field submits public YouTube Music song searches; exact results are queued for download. Local files are referenced in place with embedded artwork and are never silently moved or deleted. Library, Downloads, Queue, Devices and Settings remain useful without signing in. Account connection uses the same browser/keyring/renewal lifecycle as Tubify, in an independent credential namespace. Direct cross-app integration is deferred; there is no shared database, credential access or local HTTP API.

New downloads live inside a dedicated folder in the platform Music directory. The user may choose another Music folder; completed files retain their original absolute references. An unavailable drive must produce an actionable error, not a reset. Device sync stays bounded to its managed folder, stages and verifies files, and keeps the physical-file guard.

Settings opens from the top-right gear in Tubify’s grouped, two-column popup. The account avatar opens its Connection Settings dialog, using the same browser sign-in, cancellation, session-file and sign-out layout. Playlist actions and song actions use the same rounded overflow menus and 38 px menu items. Library/Downloads tabs, 36 px filter chips, 48 px navigation rows, 56 px playlist shortcuts, 64 px song rows and artwork cards follow the upstream composition.

Reuse Tubify’s 120 ms hover, 200 ms fade and 280 ms page/dock motion, with its easing curves and 600 ms icon tooltips. Dialog timing inherits the same Qt Basic style. Wheel notches use the upstream 120 px destination and 50 ms easing constant; touchpad scrolling remains direct. Reduced motion disables these animations. Catalogs use the upstream incremental list model: progress and busy feedback must not rebuild the song list. Shell status properties must not serialize the full catalog. Navigation, local filtering and popup opening require no provider round trip.

Verify the seven views and account/import dialogs, plus loading, empty and error states, at 920×620, 1280×820 and 1600×900. Keep synthetic previews separate from real account and device checks. Do not expose promised future integrations as disabled controls.
